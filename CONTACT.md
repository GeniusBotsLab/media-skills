## Cooperation

Use these contacts for:

- proposing an original skill or a documented improvement;
- reporting an inaccurate, unsafe, outdated, or legally sensitive recommendation;

- commercial adaptation, integration, implementation, or review.

Do not send passwords, API keys, customer exports, personal data, ad-account credentials, payment data, private repositories, or production configuration through public GitHub issues or Telegram. For a sensitive report, write a concise message by email and wait for a secure handling channel.

## Contribution standard

Contributions must state provenance. Original material should be clearly marked as original. Third-party material is accepted only with a compatible license, preserved notices, a source URL/revision, and a description of modifications. Official platform policies should be summarized in original words and linked, not copied in bulk.
